# 今日影视更新播报（DailyMediaReport）

每天汇总 Emby 中的「订阅剧集」当天新集与「电影」当天新入库内容，并经 MoviePilot 已配置的通知渠道发送一条图文播报。

## 特性

- 仅查询 `订阅剧集` 和 `电影` 两个 Emby 库，不读取合集。
- 订阅剧集按当天新入库集数合并，例如 `S01E11、S01E12`。
- 电影按 Emby `DateCreated` 识别当天入库。
- 自动将常见英文类型归一为中文。
- 默认每天只自动发送一次；详情页手动发送始终允许重发。
- 已预留“更多通知类别”页签，后续通过发版增加，不影响当前配置。
- 全程以 `【今日影视播报】` 标签写入 MoviePilot 日志：包含配置加载、Emby 请求与分页、媒体库识别、筛选统计、发送、跳过与失败。
- 不保存飞书凭据，复用 MoviePilot 的统一 `post_message` 通知链路，因此会发送到你在 MoviePilot 中配置的飞书机器人/通知渠道。
- 默认头图位于插件资源目录；也可以在设置中替换成自己的公开 HTTPS 图片 URL。

## 配置

| 配置项 | 说明 |
| --- | --- |
| 启用今日影视播报 | 开启插件。需要同时填写 Emby 地址和 API Key。 |
| Emby 地址 / API Key | 仅保存在 MoviePilot 插件配置中，用于读取媒体库。 |
| 每日通知时间 | 默认 `21:00`，使用 24 小时制 `HH:MM`，遵循 MoviePilot 服务器时区。 |
| 播报头图 URL | 通知渠道能访问的公开 HTTPS 图片。默认使用本插件发布后的 GitHub Raw 资源。 |
| 校验 HTTPS 证书 | 自签名证书可关闭；公网有效证书建议开启。 |
| 同一天只自动发送一次 | 避免定时服务重复推送；不影响详情页的手动发送。 |

## 通知格式

通知包含标题、头图、当日总数、剧集更新和新片入库两个区块；**不包含简介和末尾入库时间**。

MoviePilot 的飞书通知通道会按其原生图文卡片样式渲染 `title`、`text` 与 `image`，插件本身不依赖桌面端 `lark-cli`，因此可在 Docker 中正常运行。

## 使用

1. 在 MoviePilot 插件市场安装并启用“今日影视更新播报”。
2. 填入 Emby 地址、API Key，并确认 MoviePilot 已配置能够发送到目标飞书群的通知渠道。
3. 按需调整每日通知时间与头图 URL，保存配置。
4. 在插件详情页点击“立即发送今日播报”测试；无今日条目时不会发送空消息。

## 注意事项

- “今天”取 MoviePilot 服务器当前时区；建议服务器使用 `Asia/Shanghai`。
- 头图 URL 必须允许飞书通知渠道从公网访问。不要把带 Emby API Key 的图片 URL 用作头图。
- `run_once` 仅在保存后触发一次，并自动复位。
- 在 MoviePilot 的系统日志中按 `今日影视播报` 搜索，即可查看插件完整执行日志。
